DeryCoin (DERY)

A fixed-supply ERC-20 token project with holder burning, no buy/sell tax and a documented deployment process. Built to demonstrate DeryCode's Solidity engineering capabilities.

Project Overview

DeryCoin (DERY) is an ERC-20 token project with a planned supply of 10,000,000 tokens and 18 decimals. The repository recommends Polygon PoS as the first mainnet and a DERY/USDC trading pair on QuickSwap.

Those network and trading choices are launch plans, not confirmation of an active mainnet deployment or liquidity pool.

Source-Documented Features

  • ERC-20 token named Derycoin with symbol DERY
  • Fixed supply of 10,000,000 tokens, with no post-deployment minting
  • Holder-initiated token burning
  • No token-level buy/sell tax
  • Standard transfers and allowances
  • Compilation, testing and deployment instructions in the repository

Technology Stack

SolidityERC-20HardhatPolygon PoS (recommended)

The Engineering Focus

The project focuses on predictable token supply, standard transfer behavior and holder burning. Its automated test suite covers metadata, supply, transfers, allowances, burning and ownership changes.

Deployment Process

The repository documents compilation and testing, followed by deployment to Polygon Amoy before a potential Polygon mainnet launch. Source verification and liquidity creation are separate launch steps.

This case study does not claim a completed mainnet deployment, an independent security audit, staking, governance or a production token dashboard.

Project Evidence

Review the contract source, test suite and launch checklist in the DeryCoin repository. A live launch should be verified using a published contract address and block-explorer record.
