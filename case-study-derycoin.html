Project Overview

DeryCoin (DRC) is an ERC-20 community utility token developed by DeryCode to showcase blockchain development capabilities in Uganda. The token includes staking mechanisms, governance features, and a full web-based dashboard for token holders to manage their assets.

The project demonstrates DeryCode's expertise in smart contract development, DeFi integrations, and Web3 application development — positioning the company as a blockchain leader in East Africa.

Key Features

  • ERC-20 standard smart contract with minting and burning functions
  • Staking mechanism with dynamic reward calculation
  • Governance voting system for token holders
  • Full token dashboard with balance, staking, and reward tracking
  • Web3 wallet integration (MetaMask, WalletConnect)
  • Tokenomics with deflationary mechanics
  • Community-focused utility cases
  • Transaction history and analytics

The Challenge

Building a blockchain product from Uganda came with unique challenges:

  • Writing secure, audited smart contracts following ERC-20 standards
  • Implementing staking and governance without gas-heavy operations
  • Building an intuitive dashboard for users new to Web3
  • Ensuring cross-wallet compatibility (MetaMask, WalletConnect)
  • Demonstrating blockchain viability from an African developer perspective

The Solution

We wrote the smart contract in Solidity using OpenZeppelin's audited libraries, deployed via Hardhat. The staking system uses time-weighted reward calculations, and the governance module allows token holders to vote on proposals proportionally to their holdings.

The dashboard was built with React and Ethers.js, providing real-time balance tracking, staking management, and governance participation — all accessible through MetaMask or WalletConnect.

Results

  • Successfully deployed ERC-20 token with staking and governance
  • Full-featured dashboard for token management
  • Demonstrated blockchain development capability from Uganda
  • Positioned DeryCode as a Web3 development leader in East Africa
  • Token dashboard accessible to any Web3 wallet user
