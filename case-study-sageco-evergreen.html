Project Overview

SAGECO EVERGREEN Company Ltd is a real estate company based in Kyenjojo, Uganda, offering residential properties, commercial spaces, and eco-friendly land developments. DeryCode was tasked with building a complete digital platform — from property listings and broker management to AI-powered verification, escrow payments, and a mobile app.

The platform serves property buyers, sellers, and brokers across Uganda. Users browse listings, book viewings via PesaPal (MTN MoMo, Airtel Money, or card), and get connected with verified brokers within 24 hours.

Key Features v3.0

Drone & Spatial Verification

Drone mapping, LiDAR scans, 3D twins, and GPS-verified boundary GeoJSON for every property.

AI Fraud Detection

Automated checks for duplicate listings, boundary conflicts, document consistency, and suspicious pricing.

Eco-Land Investment Intelligence

Carbon potential scoring, reforestation analysis, agroforestry systems, and renewable energy suitability per property.

Programmable Escrow

Secure escrow with milestone-based fund release, GPS-verified site visits, and MTN MoMo / Airtel Money support.

Digital Land Passports

Unique verifiable passport per property with GPS coordinates, drone imagery, ownership history, and verification certificates.

Tokenized Fractional Investment

Investors buy fractional shares of land properties with token-based ownership tracking and ROI projections.

Remote Site-Visit Technology

Schedule physical, virtual, or drone site visits with GPS check-in verification and auto-generated visit reports.

Smart Property Matching

AI-powered matching algorithm scores properties against buyer budget, location, acreage, and investment goals.

Predictive Valuation & Arable Analytics

AI + comparable + satellite analysis with soil data, climate risk scoring, and crop suitability per acreage.

AI Broker (WhatsApp + Web)

Natural-language property search via WhatsApp. Parses intent, finds matches, creates broker follow-up tasks automatically.

The Challenge

SAGECO EVERGREEN needed a platform that could handle property listings while providing a seamless experience for buyers, brokers, and administrators. The key challenges were:

  • Building a scalable property management system with real-time availability
  • Integrating PesaPal for mobile money payments (MTN MoMo, Airtel Money)
  • Implementing drone-based boundary verification and fraud detection
  • Creating programmable escrow with GPS-verified fund release
  • Building a React Native app for Android users with offline-capable browsing
  • Developing an AI broker that understands natural-language property searches via WhatsApp
  • SEO optimization so properties appear in Google searches for "land for sale Uganda"

The Solution

We built the web platform using Next.js 14 with server-side rendering for SEO, backed by Supabase PostgreSQL for real-time data. 10 backend functions deployed on Base44 power the v3.0 AI features — drone verification, fraud detection, escrow, investment tokens, eco analytics, and the AI broker. The PesaPal integration handles secure payments via MTN MoMo, Airtel Money, and card. The Android app was built with React Native, sharing business logic with the web platform.

Every property listing page includes Product schema markup, canonical URLs, and Open Graph tags so they rank well in Google and look great when shared on WhatsApp and social media.

Results

  • 8 verified property listings across Kyenjojo and surrounding districts
  • 4 verified brokers actively using the platform
  • 10 AI-powered backend functions deployed and tested (v3.0)
  • 17 database tables created in Supabase for full platform data model
  • Properties appearing in Google search results for "land for sale Uganda"
  • Mobile app live on Android for on-the-go property browsing
  • AI broker successfully parsing WhatsApp queries and matching properties
