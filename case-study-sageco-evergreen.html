Project Overview

SAGECO Evergreen Company Ltd is a real estate company based in Kyenjojo, Uganda, offering residential properties, commercial spaces, and eco-friendly land developments. DeryCode was tasked with building a complete digital platform — from property listings and broker management to payment processing and a mobile app.

The platform serves property buyers, sellers, and brokers across Uganda. Users browse listings, book viewings via PesaPal (MTN MoMo, Airtel Money, or card), and get connected with verified brokers within 24 hours.

Key Features

  • Property listing platform with 500+ listings (residential, commercial, land)
  • Verified broker dashboard with property management and lead tracking
  • PesaPal payment integration for booking fees (UGX 30,000 per viewing)
  • Broker registration and subscription plans with tiered pricing
  • Android app (React Native) with property browsing and booking
  • Admin dashboard for managing properties, brokers, bookings, and messages
  • AI-powered chatbot for property inquiries
  • SEO-optimized with JSON-LD schema, dynamic sitemap, and geo-location tags
  • WhatsApp integration for instant broker contact
  • Property detail pages with image galleries, maps, and similar listings

The Challenge

SAGECO Evergreen needed a platform that could handle hundreds of property listings while providing a seamless experience for buyers, brokers, and administrators. The key challenges were:

  • Building a scalable property management system with real-time availability
  • Integrating PesaPal for mobile money payments (MTN MoMo, Airtel Money)
  • Creating a broker onboarding flow with subscription tiers
  • Ensuring fast page loads for property-heavy pages with multiple images
  • Building a React Native app for Android users with offline-capable browsing
  • SEO optimization so properties appear in Google searches for "land for sale Uganda"

The Solution

We built the web platform using Next.js 14 with server-side rendering for SEO, backed by Supabase PostgreSQL for real-time data. The PesaPal integration handles secure payments via MTN MoMo, Airtel Money, and card. The Android app was built with React Native, sharing business logic with the web platform.

Every property listing page includes Product schema markup, canonical URLs, and Open Graph tags so they rank well in Google and look great when shared on WhatsApp and social media.

Results

  • 500+ properties listed and growing
  • 200+ clients successfully connected with brokers
  • 15+ verified brokers actively using the platform
  • Properties appearing in Google search results for "land for sale Uganda"
  • Mobile app live on Android for on-the-go property browsing
